# Física 3ª série · CIB

Listas interativas de Física para a reta final do ENEM, 3ª série do Colégio Israelita Brasileiro (Prof. Ricieri), com dica e resolução passo a passo. App instalável (PWA) publicado pelo GitHub Pages.

- `fonte/`: arquivos-fonte (`enem.js` com as 3 listas da lista impressa de revisão e o formulário, `inducao.js` com as 2 listas de indução, `calorimetria.js` com a lista de Calorimetria, `ondulatoria.js` com as 3 listas de Ondulatória, `eletricidade.js` com a lista de circuitos, `engine_app.js` com `SITE` e `CONFIG`). Para montar o `index.html`: `python3 fonte/montar.py`.
- `img/`: figuras das questões da lista de revisão.
- `registro/Codigo.gs`: script da planilha de registros (Google Apps Script).
- A cada publicação, aumentar `VERSAO` em `sw.js`.
